=== ДЕФЕКТ №1 ===
ID: STR-001
Заголовок: Метод contains() некорректно обрабатывает пустую подстроку
Серьезность: Средняя
Приоритет: Средний
Описание:
Метод contains() возвращает True при поиске пустой подстроки в любой строке.

Шаги воспроизведения:
1. Вызвать utils.contains("any_string", "")
2. Проверить возвращаемое значение

Ожидаемый результат: False (пустая строка не должна считаться содержащейся)
Фактический результат: True

Влияние: Логические ошибки при проверке наличия символов в строках.

=== ДЕФЕКТ №4 ===
ID: STR-004
Заголовок: Метод is_empty() не учитывает табы и переносы строк как пробелы
Серьезность: Низкая
Приоритет: Низкий
Описание:
Метод is_empty() возвращает False для строк, содержащих только табы или переносы строк.

Шаги воспроизведения:
1. Вызвать utils.is_empty("\t")
2. Вызвать utils.is_empty("\n")
3. Проверить возвращаемые значения

Ожидаемый результат: True (строки из whitespace-символов должны считаться пустыми)
Фактический результат: False

Влияние: Несогласованность в определении "пустых" строк.

=== ДЕФЕКТ №5 ===
ID: STR-005
Заголовок: Метод list_to_string() некорректно обрабатывает пустой разделитель
Серьезность: Низкая
Приоритет: Низкий
Описание:
При использовании пустого разделителя метод добавляет его между элементами, но результат выглядит как конкатенация без разделителей.

Шаги воспроизведения:
1. Вызвать utils.list_to_string(["a", "b", "c"], "")
2. Проверить возвращаемое значение

Ожидаемый результат: "abc" (элементы без разделителей)
Фактический результат: "abc" (корректно, но документация неясна)

Влияние: Недостаточная документация поведения метода.

=== РЕКОМЕНДАЦИИ ===
1. Исправить обработку пустых подстрок в методах contains(), starts_with(), end_with()
2. Расширить определение "пробельных" символов в методе trim() и is_empty()
3. Уточнить документацию для метода list_to_string()
4. Добавить обработку граничных случаев для всех методов
