 Дипломная работа: Автоматизация тестирования сайта "Читай-город"

## Описание проекта
Дипломный проект по автоматизации тестирования интернет-магазина "Читай-город". Проект содержит автоматизированные UI и API тесты для проверки основных функций сайта.

### Тестовое покрытие:
- **UI тесты**: 5 тестов (4 успешных, 1 пропущен)
- **API тесты**: 5 тестов
- **Итого**: 10 тестов

## Структура проекта
Diplom/
├── tests/
│ ├── test_ui.py # UI тесты (Selenium WebDriver)
│ └── test_api.py # API тесты (Requests)
├── config.py # Конфигурационные параметры
├── conftest.py # Фикстуры Pytest
├── requirements.txt # Зависимости Python
├── pytest.ini # Конфигурация Pytest
├── .env.example # Пример файла с переменными окружения
└── README.md # Документация

## Технологии
- **Python 3.13+**
- **Pytest** - фреймворк для тестирования
- **Selenium WebDriver** - автоматизация UI тестов
- **Requests** - HTTP запросы для API тестов
- **Allure** - генерация отчетов
- **WebDriver Manager** - управление драйверами браузеров
